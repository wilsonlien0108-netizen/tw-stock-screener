# 台股均線籌碼篩選器

篩選**同時站上短期均線（預設 5/10/20 日）**的上市/上櫃普通股，並整合：

- **三大法人**（外資、投信、自營商）每日買賣超與連續買超天數
- **大戶/散戶籌碼**（集保戶股權分散表，每週五更新；大戶門檻 100–1000 張可調）
- **技術指標與動能**：KD、RSI、MACD、布林通道、乖離率、**相對強弱 RS**
  （90 日報酬全市場百分位），全部可當篩選條件
- **融資融券**：融資餘額/增減、「融資連 N 日減」籌碼沉澱篩選
- **基本面與營收動能**：月營收 YoY/MoM、**營收創 N 月新高**、**YoY 連續 N 月正成長**
  （24 個月歷史）、本益比/殖利率/股價淨值比
- **策略管理**：條件組合可命名儲存、一鍵切換，並可多策略排程推播
- **自選股清單＋盤中警示**：不限檔數；到價/漲跌幅/爆量警示（盤中模式觸發桌面通知）
- **盤中 K 棒監控**：獨立常駐程式每 20 秒取樣自建 1分/5分 K 棒，
  偵測「1分K連 N 根收紅」「5分K連 M 根收紅」（AND/OR 可調）即 LINE＋桌面通知；
  平日 08:58 可排程自動啟動、13:32 自動收工（`設定盤中監控排程.bat`）
- **兩段式回測**：① 條件勝率統計（篩選頁自動標註歷史勝率）
  ② 完整策略回測 — 次日開盤進場、停損停利、非重疊持有、交易成本、
  排除漲停買不到、資金曲線與最大回檔、交易明細匯出
- **大盤儀表板**：加權指數、漲跌家數、市場寬度（站上 20MA 比例）、
  三大法人全市場合計、產業漲跌
- **盤後推播**：每日排程更新後自動推送篩選結果（Windows 桌面通知／LINE），
  更新失敗也會告警
- **一鍵資料健檢**：完整性掃描＋獨立官方端點抽樣比對＋指標演算對照
- **自動維運**：每週資料庫備份（保留 4 份）、逾兩年資料自動修剪、
  不完整交易日自動偵測重抓
- **概念股標籤**：AI、機器人、軍工（內建可編輯清單）、電子（官方產業分類）
- **盤中即時模式**：以證交所 MIS 即時報價重算均線與指標，每 1–10 分鐘自動刷新

## 安裝與啟動

**一般使用者（免安裝）**：資料夾內含可攜式 Python（`runtime/`），直接雙擊
`啟動篩選器.bat` 即可，詳見 `使用說明.txt`。

**開發者**：

```powershell
cd tw-stock-screener
py -m pip install -r requirements.txt
py -m streamlit run app.py
```

首次啟動請按「初始化」下載歷史資料（官方介面有速率限制，約 4–10 分鐘）。

## 每日自動更新（選用）

以系統管理員開 PowerShell 執行一次：

```powershell
.\scripts\setup_scheduler.ps1
```

之後每個平日 20:30 自動抓當日盤後資料並依設定推播（紀錄在 `data/update.log`）。
手動更新：`py scripts\daily_update.py`（`--full` 回補 60 日；`--year` 回補一年供回測，
約 40–50 分鐘，也可在 App「資料與設定」按「回補一年歷史」於背景執行）。

## 分享給家人朋友的手機（沒有電腦也能用）

詳見 **《手機部署指南.md》**，兩種方式：

1. **雲端版（日常用）**：程式碼放你的 GitHub → Streamlit Cloud 免費託管 →
   家人開固定網址、加到手機主畫面。你的電腦每晚更新後自動上傳資料
   （「資料與設定 → ☁️ 雲端發佈」設定一次即可）。雲端版無盤中即時
   （證交所擋海外 IP）與推播，其餘功能完整。
2. **通道版（臨時全功能）**：雙擊 `雲端通道啟動.bat`，把畫面上的
   trycloudflare 網址傳給對方；含盤中即時，但你的電腦要開著、網址每次會變。

## 分享給其他設備 / 他人

**同一區網（手機、平板、家人電腦）**：

```powershell
# 首次先以系統管理員放行防火牆（一次即可）
New-NetFirewallRule -DisplayName "TW Stock Screener" -Direction Inbound -Protocol TCP -LocalPort 8501 -Action Allow
# 之後都用這個啟動
.\scripts\start_server.ps1
```

啟動後其他設備開瀏覽器連 `http://<本機IP>:8501`（腳本會印出實際網址）。

**不在同一區網（外出用手機看）**：安裝 [Tailscale](https://tailscale.com)（免費）
在這台電腦和手機上登入同一帳號，然後用 Tailscale 分配的 IP 連 8501 埠即可，
不用開公網、也不用改任何程式。

**臨時給朋友看一下**：`cloudflared tunnel --url http://localhost:8501`
（[下載 cloudflared](https://github.com/cloudflare/cloudflared/releases)）會產生一個
臨時公開網址，關掉視窗即失效。注意：App 沒有登入機制，拿到網址的人都能操作。

**複製到另一台電腦**：整個資料夾拷貝過去即可（免安裝，`runtime/` 內含
可攜式 Python；含 `data/` 就不用重新初始化），對方雙擊 `啟動篩選器.bat` 使用。
注意：只支援 64 位元 Windows。若透過網路傳送 zip，對方解壓前先在檔案上
按右鍵 → 內容 → 勾「解除封鎖」。

## 資料品質與已知限制（2026-07-14 全面驗證後記錄）

- **完整性自動修復**：每次更新會偵測「筆數異常偏低的日期」（單邊來源失敗造成）
  並自動重抓；抓取層並會驗證回應內的日期與請求日期一致，防止休市日被寫入
  前一日的重複資料。
- **停牌股**：均線／布林等 rolling 類條件要求視窗內每日都有交易，
  停牌中或剛復牌的股票會被排除（保守設計）；KD/RSI/MACD 則會跳過缺口正常銜接。
- **集保股權分散**：少數股票（約 0.4%）因官方檔的「差異數調整」級距以絕對值列示，
  各級距加總會略超過 100%，本工具照實呈現官方原值。
- **月營收**：金控股不申報月營收（顯示空白為正常）；每月 10 日申報截止，
  遲交公司會在其後幾天的每日更新中自動補齊。
- **回測基準**：「全市場同期平均」為所有普通股的等權平均報酬，非市值加權指數。

## 注意事項

- **大戶週變化**需累積兩週集保資料；第一週可到「資料與設定」用 FinMind
  逐檔回補 8 週歷史（免費額度有限，建議只回補概念股）。
- MIS 即時報價為非官方介面，過度頻繁查詢可能被暫時封鎖；預設節流已保守。
- 概念股清單無官方定義，內建清單僅為起點，請在「概念股清單管理」中自行維護，
  或貼財經網站概念股頁面網址一鍵匯入。
- 本工具僅供研究參考，不構成投資建議。
